### F8. [BLOCKER] `RegisteredRun` has no rebindable output sink — every emission path (`onMessage`/`onClearRunMessages`/`session_ended`/`error`/permission rebroadcast) closure-captures the dead per-connection `send`; the contract's "reattach → running → re-route" is structurally inert

The `claude` subprocess's `onMessage` is bound at `runSession({...})` call time to the connection-scoped `send` (index.ts:438, captured by the arrow fn at :586). After ws_close (and I-12 says do NOT abort), the subprocess keeps producing → calls the closure → writes to a closed socket → frames dropped by ws. `reattach_run` returning `status:"running"` therefore promises a re-route that the data model cannot perform.
**Why blocker**: Contract mode + the contract's *primary capability* ("run survives disconnect AND iOS reattaches to see continued output") is **non-functional as specified** — `running` is a hollow status.
