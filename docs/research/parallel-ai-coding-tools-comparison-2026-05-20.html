研究问题

Vessel 自研并行开发协调方案（git worktree + eva.json + BACKLOG.md + 文件 flag 完成信号 + Steward I11 dispatch）与 claude-squad、workmux、dmux、uzi、Seshions、ccmanager、Nimbalyst、VibeTree 等工具横向对比，评估架构设计、完成信号可靠性、单人认知负担、冲突检测、可扩展性五个维度，明确 Vessel 自研路线的合理性和待补设计。

核心发现

F1：Vessel = 协议化控制平面，非 TUI 编排 高置信度

claude-squad/workmux/dmux 的主体是 worktree+tmux+TUI 生命周期管理；Vessel 多了 eva.json 任务注册表、所有权声明、I11 dispatch。两类互补，不是替代关系。

F2：Claude Code Stop hook 可自动化 worker 主动调脚本步骤 高置信度

Claude Code 在 Stop/PermissionRequest/UserPromptSubmit 触发 hook。workmux 已用此实现三态自动更新。Vessel 目前需 worker 手动调 steward-signal-done.sh，Stop hook 可消除这步。

F3：冲突检测 Vessel 领先，但 parallel_safe_files 是 work-order 层约束 高置信度

业界标准用 git merge-tree 三路预检。Vessel 的声明式文件所有权在调度层约束，不阻止 FS 写入。可进一步加固：spawn 时跑 merge-tree，或 git hooks 在 commit 时拦截。

F4：I11 dispatch 模式符合业界最优认知负担模式 高置信度

"每 5-10 分钟异步 check-in"是效率最高工作方式（Addyosmani / htdocs.dev 多来源背书）。Vessel I11 dispatch + pnpm eva:collect 周期收线完全符合 Tier 2 Local Human-in-the-Loop 最优模式。

F5：2025-2026 生态重心已转向多模型、跨平台、可视化 高置信度

claude-squad 已支持 Codex/Gemini/Aider；workmux/dmux 支持多模型；Nimbalyst/VibeTree 提供 iOS/桌面。Gemini CLI 2025 发布（1M context + 免费）改变了格局。

推荐

✅ Vessel 自研路线合理 — 不建议迁移到 claude-squad

冲突预检机制是差异化优势，建议实施 3 项改进（P4-P6）

置信度：中高（25 个有效来源，核心 claim ≥2 独立来源）

理由

  1. parallel_safe_files + eva-conflict-check.mjs 是业界独有的冲突预检机制，迁移到 claude-squad 会直接丢失这个优势
  2. I11 dispatch（人工拍板）符合 Tier 2 最优认知负担模式，有多来源明确背书
  3. claude-squad 核心竞争力在 TUI 可视化，非协议语义，不在同一竞争层面
  4. workmux 设计思路与 Vessel 同构，可吸收其 Claude Code Stop hook 而无需整体迁移
P4（高优先） 接入 Claude Code Stop hook

配置 ~/.claude/settings.json 的 Stop hook 指向 steward-signal-done.sh $TASK_ID。消除 worker 忘记手动调脚本的风险（当前最弱环节）。实现成本低（配置级），价值高。

P5（中优先） .env 自动同步到 worktree

在 eva.json hooks.post-create 中标准化 .env 文件拷贝逻辑。参考 Claude Code 官方 .worktreeinclude 设计或 claude-squad Issue #260 讨论方案。

P6（低优先） PTY-level 三态检测

参考 ccmanager PTY 输出流分析或 tmux display-message + window-title 变化，让主线实时感知 worker 三态（Working/Waiting/Done）。

何时应迁移到 claude-squad / workmux

  • 需要多模型（Codex/Gemini）并行 + TUI 操作界面，且不需要文件级冲突预检
  • 维护 eva.json 自定义逻辑成本超过现成工具覆盖收益
  • 项目从个人单机转向多人协作

⚠️ 本建议仅适用于个人单机 1 人开发者场景
